# i18n

1. **Always ask before translating ambiguous strings.** Do not guess or auto-translate; batch the
   questions by component and wait for confirmation.
2. Strings that appear in more than one component use a shared `common.*` key.
3. Croatian domain and legal terms are **never translated**; keep them as literal values in both
   `hr` and `en`.
4. After any i18n change, re-scan the affected components for missed hardcoded strings.
5. The language switcher respects the user's stored preference (`users.language`); the browser
   locale is only the fallback before sign-in.
