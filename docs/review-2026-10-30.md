# Review of the skeleton after Part 7 (2026-10-30)

A read-only review of `main` at `ff6e2b9` by five reviewers, one per area, each checking the code
against the ten invariants, its plan part and its doc. Every finding names a file and line. **Verify
each one before acting on it**: "Confirmed" means the reviewer traced the path end to end (and the
top four were re-read independently); "Plausible" means a reading that nothing executed. A finding
that turns out wrong is closed with one line saying why, not silently dropped.

Sizes: High = a user would hit it or data goes wrong; Medium = wrong output, a secondary flow, or a
contract broken; Low = inconsistency, dead code, missing guard.
